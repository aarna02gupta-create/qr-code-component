# QR Code Component

An HTML/CSS practice exercise based on the Frontend Mentor QR code component challenge. The page uses a card layout and Flexbox.

## View locally

Open `index.html` in a browser; no build step or package installation is required.

## Current limitation

The HTML references `images/image-qr-code.png` and `images/favicon-32x32.png`, but those assets are absent from this repository. The QR image will not render until the original challenge assets are restored under `images/`.

[Original challenge](https://www.frontendmentor.io/challenges/qr-code-component-iux_sIO_H).
